Now Lets run some Basic commands of MySQL

1. To Get the List of All Databases:
> show databases 

2. to create database
> create database pwskills;

3. To Use the database
> use <name of database>

4. Create Table in Database
> create table students (id int auto_increment primary key, name varchar(200), email varchar(200));

5. get the list of all available tables;
> show tables;

6. to get the description of Table
>  describe <name_of_table>

7. insert a value in table
> insert into students (name,email) values("Nikunj Soni","nikunj@pw.live");

8. get the list of all data in a table
> select * from students
